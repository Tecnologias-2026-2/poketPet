🎯 1. Objetivo General

Desarrollar una aplicación móvil y web que ayude a los jóvenes a crear el hábito del ahorro y a administrar su dinero, usando una mascota virtual motivadora, metas de ahorro y contenido educativo. Busca resolver la falta de control de gastos, de metas de ahorro y de conocimiento financiero en los jóvenes.

🌍 2. Contexto de Uso

¿Quién va a usar el sistema? jóvenes de 16 a 28 años (estudiantes, primer empleo o ingresos variables).
¿Cómo se va a utilizar el sistema? desde el celular o la web, para registrar gastos e ingresos, revisar metas, aprender finanzas y ver el estado de la mascota.

📋 3. Requerimientos del Sistema
3.1 Requerimientos Funcionales

RF01: El sistema debe permitir registrar usuarios e iniciar sesión.
RF02: El sistema debe permitir registrar ingresos y gastos.
RF03: El sistema debe permitir organizar los gastos por categorías.
RF04: El sistema debe permitir crear metas de ahorro y ver su progreso en porcentaje.
RF05: El sistema debe mostrar una mascota virtual que refleje los hábitos financieros.
RF06: El sistema debe  ofrecer una sección educativa con conceptos básicos de finanzas personales.
RF07: El sistema debe enviar recordatorios de fechas de pago.

3.2 Requerimientos No Funcionales

Escriban cómo debe comportarse el sistema.

RNF01: La aplicación debe ser responsive (móvil y web).
RNF02: La interfaz debe ser simple y en español claro.
RNF03: Las contraseñas deben guardarse de forma segura.
RNF04: Las funciones principales deben ser gratuitas.
RNF05: Buen rendimiento y tiempos de carga rápidos. Seguridad y protección de datos financieros.
